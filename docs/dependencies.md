# Bağımlılık ve veri lisansı envanteri

Kontrol: **2026-10-22**. Home'un dağıtım lisansı henüz seçilmedi. Aşağıdaki kayıt kod/veri sağlayıcılarının lisansını belirtir; dış hizmet aboneliği veya dağıtım hakkı uydurulmaz.

**2026-10-22 / CasaOS registry publication:** build-only GitHub checkout/artifact actions (**MIT**) and Docker Buildx/login/build-push actions (**Apache-2.0**) are pinned to official release commits. These run in CI and are not application runtime services. Exact versions, source references, container visibility and verification status are in [CASAOS-REGISTRY-043](casaos-registry-043.md). The image retains the existing component-specific licence notices and native corresponding-source archive; public package access is not a new blanket licence for those components or provider media.

**0.43 headless/LAN:** Linux x64 container now builds the already-selected RetroArch/mGBA/FCEUmm/Snes9x/Genesis Plus GX/PCSX ReARMed stack from fixed source commits and uses MediaMTX 1.21.2. Actual source, licence and build metadata live in `deploy/native/sources.json` and the image's `NativeRuntime/licenses/`. Snes9x/Genesis non-commercial conditions mean this local personal-use build is not evidence of commercial/public distribution clearance. Xvfb/Mesa software OpenGL is a headless context adapter; no GPU performance claim. Diagnostic-only QEMU/Ubuntu/7-Zip/gdb and aiortc 1.15.0 (BSD-3-Clause), aiohttp 3.14.5 (Apache-2.0/MIT), PyAV/libSRTP are verification tools, not application services. [Pins, sources and verification](headless-lan-043.md).

**2026-10-22 / 0.42 Live TV:** IPTV-org public M3U list endpoints reviewed; actual repository LICENSE is **Unlicense/public-domain dedication**, alongside a CC0 README badge. Home ships twelve source descriptors and its original bounded parser/adapter; it does not embed provider code or a channel database dump. Channel/logo media rights stay with broadcasters and are not covered by the repository license. List previews/probes read metadata only; source addition and Watch remain explicit user commands. Existing **Video.js 10.1.0 / hls.js 1.7.3 (Apache-2.0)** and configured FFmpeg are reused. [Source/license references and protocol verification](live-tv-experience-042.md).

**2026-10-21 / 0.41.1 Music follow-up:** six additional freely licensed Commons clips expand the curated video choices to ten; new source/author/CC0 or CC BY(-SA) records and selected derivative URLs were verified through the public text API. Exact [source table and receipts](music-refinements-0411.md). The prior procedural nature scenes were deleted; a shared original Home vinyl illustration is the sole local visual fallback. No stock binary, new dependency or dataset dump is bundled. MusicBrainz prefix search continues to use the same public core-data API and rate limit.

**2026-10-21 / 0.41 Music:** existing MusicBrainz core **CC0** + copyrighted CAA artwork are optional, profile-private cache/enrichment sources. Radio Browser station contributions are **public domain** ([provider notice](https://www.radio-browser.info/add)); the public API is keyless, and its GPL/AGPL server code is not embedded. Station audio remains the broadcaster's content. Existing Apache-2.0 **hls.js 1.7.3** is reused. No provider wrapper, dataset dump or replacement playback engine was adopted. Visual mode references four individually reviewed Commons videos (**CC BY 3.0 / CC BY-SA 3.0 / CC BY-SA 4.0 / CC BY 2.0**) and three AIC public-domain Monet images (**CC0**, API field verified); source/author/license and mute/loop/crop notices are visible. Media loads only in user-selected visual mode and is not bundled. Offline canvas scenes are original Home decorations. [Exact media provenance, API references and evidence](music-experience-041.md).

**2026-10-21 / 0.40.0 Games presentation and automation:** no new dependency/data dump/API key. `web/src/gaming/ConsoleArt.tsx` contains original decorative vector silhouettes and console-family colors, not copied publisher logos/game artwork or a new external asset dataset. Hasheous details-tool error recovery uses the same public search API and exact provider identity; production automatic enrichment/region selection follows the user's collection-wide request. Development verification requested public text metadata only, with no image/game/BIOS download. Existing libretro publisher copyright and Hasheous underlying-data/public-distribution gates still apply. [Sources and evidence](games-experience-040.md).

**2026-10-21 / implemented public ROM metadata adapter, 0.39.0:** original C# HTTP client for Hasheous' documented hosted **public MCP lookup/search/details** contracts; no user API key, server code, SDK/wrapper, plugin or dataset adopted. Hasheous source is **AGPL-3.0**, distinct from API/data/media rights; no source embedded into Home. Ordinary Hasheous IGDB proxy endpoints require their own client API key and are not used by this keyless path. Hosted free access does not grant unrestricted redistribution of underlying DAT/IGDB data. Cache only private user-command records, preserve attribution and manual fields; public/commercial licensing remains open. Existing public libretro cover adapter now reads the actual directory listing rather than a nonexistent `.index`. Publisher/artwork copyright still applies. [Exact implementation, limits, source references and verification](gaming-settings-metadata-039.md).

**2026-10-21 / ROM metadata API candidates — not adopted:** ScreenScraper API v2 reviewed for CRC/MD5/SHA1/system/serial ROM identification. Official API documentation requires application-specific developer access and limits integration to entirely free distributed apps unless their team authorizes other conditions; site notice **CC BY-NC-SA 4.0**, with third-party publisher/media rights still distinct. IGDB v4 reviewed as additional game metadata; Twitch client credentials, documented rate limits and getting-started non-commercial/partnership terms apply (FAQ wording is not blanket commercial clearance). No provider wrapper/code/dataset was adopted, no credential/account requested, and no API game/media acquisition performed. Home licence/access approval, correct disc fingerprints and secret/media-URL redaction remain gates. [Exact sources and proposed workflow](gaming-settings-metadata-proposal.md).

**2026-10-21 / basic selection software setup:** the user explicitly requested installing the missing basic emulators. Home installed only **FCEUmm (GPLv2), Snes9x (Non-commercial), Genesis Plus GX (Non-commercial), PCSX ReARMed (GPLv2)** from official Windows x64 buildbot core packages; **23,990,715 bytes** of received DLLs, immutable SHA-256/channel/source/archive/info receipts in managed state and `artifacts/basic-native-cores-v038.json`. They are separately acquired software, **not bundled in the Home ZIP**, not a ROM/BIOS/data acquisition, not untouched stable-release/source-correspondence claims. The non-commercial cores cannot be assumed compatible with an eventual commercial Home distribution. Reviewed released mGBA and existing Citra remain unchanged. Source references / current readiness / public redistribution gates: [basic selection](gaming-basic-selection-038.md).
